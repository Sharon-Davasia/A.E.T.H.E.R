# ADR-013: AETHER working identity; legal/name check pending

**Status:** Pending validation (V-06)
**Date:** 2026-11-14 (master spec v1.0)

## Context

The product needs a name, acronym, visual identity, and personality
that feel trustworthy daily. Public branding requires legal clearance.

## Decision

Working name: **AETHER OS** (formerly project JARVIS). Acronym:
**A**utonomous **E**ngine for **T**ask **H**andling, **E**valuation &
**R**esponse. Wake phrase configurable (default "Hey Aether").
Visual identity per ADR-010. Legal/name-conflict search and user
choice are required before public branding.

## Alternatives considered

Continuing as "JARVIS" (rejected: existing-character association;
working name changed to AETHER).

## Consequences

- **Not cleared for public distribution.** V-06 must complete
  licensing and name search.
- Phase 0 uses "AETHER OS" as the working name only.
